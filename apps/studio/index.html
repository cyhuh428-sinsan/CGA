API

External API Answer Source

API answers are used when the response is not fixed text but comes from an external business system.

Group-managed API

API answers belong to the group bot, not to an individual user. Secret references and response mappings are controlled by group permissions.

Answer flow

User questionMatched intentExternal system APIBot answer

Group API Registry

Register external API answers by group. These are bot assets controlled by group permissions.

Dynamic data answer example

For values that change over time, such as company revenue or net income, CGA stores the intent and API mapping, then calls the external system at answer time.

Question: What is this company’s latest net income? API: GET /financials/{company_id}/net-income Answer: Net income is shown from the latest external API response.
