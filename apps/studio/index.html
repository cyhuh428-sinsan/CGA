CO

Collaboration Platform

CGA is optimized for one person to build a bot in 1-2 days, while still allowing multiple people to collaborate on the same bot when needed.

Fast solo first

The default flow should let one builder create, configure, test, and deploy a bot quickly without collaboration overhead.

Team expansion

When a bot grows, intents, answers, scenarios, API answers, deployments, and evaluations can be assigned to different users.

Review workflow

Generated or edited content moves through review before it becomes approved bot content.

Edit locks

When multiple users edit, short-lived locks prevent conflicting changes on the same item.

Change history

Every important change should keep actor, time, target, before/after summary, and review result.

Team dashboard

API

External API Answer Source

API answers are used when the response is not fixed text but comes from an external business system.

Group-managed API

API answers belong to the group bot, not to an individual user. Secret references and response mappings are controlled by group permissions.

Answer flow

User questionMatched intentExternal system APIBot answer

Group API Registry

Register external API answers by group. These are bot assets controlled by group permissions.

Dynamic data answer example

For values that change over time, such as company revenue or net income, CGA stores the intent and API mapping, then calls the external system at answer time.

Question: What is this company’s latest net income? API: GET /financials/{company_id}/net-income Answer: Net income is shown from the latest external API response.
