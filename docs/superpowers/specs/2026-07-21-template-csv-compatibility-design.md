# Aidot 템플릿 CSV 호환성 수정 설계

## 목적

Aidot에서 내려받은 템플릿 CSV를 CGA에 다시 올릴 때 `SM_CHAT` 또는 `WEBCHAT`의 `carousel` 행에서 업로드가 중단되는 문제를 수정한다. 기존 템플릿 데이터와 채널 코드는 변경하지 않는다.

## 확인된 원인

- CSV는 UTF-8이며 현재 CGA 내보내기/가져오기 헤더 형식과 일치한다.
- CGA에는 `SM_CHAT / Carousel`과 `WEBCHAT / Carousel`이 정상 데이터로 존재한다.
- API 검증 함수가 `carousel`을 모든 비-KAKAO 채널에서 금지한다.
- 업로드는 행별 API 요청을 순차 실행하고 첫 오류에서 중단한다. 오류가 발생하면 목록 재조회도 수행하지 않아 앞선 반영 결과가 화면에 나타나지 않는다.

## 변경 설계

### 1. 서버 렌더러 검증

- KAKAO 채널은 기존 허용 목록(`simple-text`, `quick-reply`, `basic-card`, `list-card`, `carousel`)을 유지한다.
- KAKAO 전용 렌더러 판정에서는 `carousel`을 제외한다.
- 따라서 `SM_CHAT`과 `WEBCHAT`은 `carousel`을 사용할 수 있다.
- `simple-text`, `quick-reply`, `basic-card`, `list-card`는 계속 KAKAO 전용으로 제한한다.

### 2. CSV 업로드 결과 처리

- 현재 CSV 구조와 기존 등록/수정 판정은 유지한다.
- 각 행의 API 오류를 개별 수집하고 다음 행 처리를 계속한다.
- 성공 건수, 제외 건수, 실패 건수와 첫 실패 행의 채널·템플릿명·오류 원인을 화면에 표시한다.
- 성공 여부와 관계없이 마지막에 목록을 다시 조회하여 실제 반영 상태를 보여준다.
- 파일 형식상 필수 값이 없는 행은 기존처럼 제외 처리한다.

## 영향 범위

- API: 관리자 템플릿 렌더러 유효성 검사
- Web: 관리자 템플릿 CSV 업로드 결과 처리
- DB 스키마와 기존 데이터에는 변화가 없다.
- 템플릿 직접 등록/수정 화면은 같은 서버 검증 규칙을 사용하므로 `SM_CHAT`과 `WEBCHAT`의 `carousel` 수정도 정상화된다.

## 테스트

- API 단위 테스트로 `SM_CHAT/WEBCHAT + carousel` 허용을 검증한다.
- 기존 KAKAO 허용 목록과 다른 채널의 KAKAO 전용 렌더러 차단이 유지되는지 검증한다.
- Web 계약 테스트로 업로드가 행별 오류 후에도 계속되고, 마지막에 목록을 다시 불러오며, 실패 정보를 표시하는지 검증한다.
- API 테스트, Web 정적 검사 및 빌드를 실행한다.

## 제외 범위

- CSV 일괄 업로드 전용 신규 API 추가
- DB 트랜잭션 구조 변경
- 채널 관리 화면 또는 템플릿 데이터 자동 변환
- 관련 없는 관리자 화면 수정
