# 의도/모듈 관리 화면 다국어 설계

## 1. 목적

`의도/모듈 관리` 화면의 사용자 인터페이스를 CGA Studio 공용 7개 언어(`ko`, `en`, `zh-CN`, `ja`, `vi`, `fr`, `de`)로 표시한다. 사용자 작성 데이터와 저장·학습·대화 실행 계약은 변경하지 않는다.

## 2. 범위

다음 표시 문구를 선택한 화면 언어에 맞춰 전환한다.

- 요약 카드와 검색 조건
- 목록 개수, 페이지 크기, 선택·삭제 동작
- 표 머리글과 접근성 레이블
- 빈 목록·로딩·오류 메시지
- 삭제 확인 대화상자
- 파일 업로드 안내와 업로드 결과
- 대화 설계 오류의 화면용 안내 문구

다음 항목은 이 작업에서 변경하지 않는다.

- `/api/v1` 요청 경로와 요청·응답 구조
- 봇·버전·의도·모듈 UUID
- 의도 저장, 삭제 참조 검사, 학습, 대화 설계 로직
- 사용자 작성 의도명·표시명·학습문장·태그
- CSV 열 순서와 기존 한글·영문 헤더 인식 별칭
- 다운로드 CSV의 기존 호환 형식

## 3. 구현 경계

### 3.1 표시 카탈로그

`intent-list-page.tsx` 전용 7개 언어 카탈로그를 추가한다. 화면에 표시되는 문구는 현재 `useI18n()` 언어에 대응하는 카탈로그에서 읽는다.

공용 AI/NLU 명칭과 셸 메뉴 명칭은 이미 존재하는 공용 카탈로그를 재사용한다. 사용자 데이터나 API 오류 상세문은 자동 번역하지 않는다.

### 3.2 CSV 호환성

CSV 파서가 인식하는 `의도명`, `표시명`, `의도 Key`, `학습문장`, `태그`와 기존 영문 별칭은 데이터 계약이므로 번역 카탈로그로 이동하지 않는다. 화면의 업로드 설명만 번역한다.

CSV 다운로드도 기존 열 순서와 헤더를 유지한다. 이번 단계에서 언어별 CSV 포맷은 만들지 않는다.

### 3.3 오류 처리

클라이언트가 직접 생성하는 고정 안내 문구는 번역한다. API가 반환한 구체적인 오류 메시지는 원인을 훼손하지 않도록 그대로 표시한다.

대화 설계 오류의 개수·대상 UUID·참조 위치 계산은 기존 함수를 유지하고, 앞뒤 설명 문구만 현재 화면 언어로 조립한다.

## 4. 단계별 적용

1. **목록과 검색**: 요약 카드, 검색·필터, 표 머리글, 빈 상태, 페이지 크기.
2. **선택과 삭제**: 선택 개수, 삭제 버튼, 참조 차단·삭제 확인 안내.
3. **CSV 업로드**: 업로드 창, 안내, 결과 집계 문구. 파서·다운로드 포맷은 유지.
4. **대화 설계 오류**: 학습 차단과 오류 위치 안내 문구.

각 단계는 별도 RED/GREEN 계약 테스트와 Next.js 전체 빌드를 통과한 뒤 커밋한다.

## 5. 기존 기능 유지 기준

변경 전:

- 고정 화면 문구가 한국어로 직접 작성되어 있다.
- CSV 데이터 계약 문자열과 화면 문구가 같은 파일에 혼재한다.

변경 후:

- 화면 문구만 현재 화면 언어 카탈로그에서 가져온다.
- CSV 데이터 계약, API 호출, 상태 갱신, 학습·삭제 행위는 기존 코드와 동일하다.

## 6. 완료 조건

- 7개 언어 카탈로그가 타입 검사로 완전성을 보장한다.
- 언어 전환 시 페이지 이동 없이 목록·검색·대화상자 문구가 갱신된다.
- 기존 CSV 파일 업로드·다운로드 계약이 유지된다.
- 의도 저장·삭제·학습·대화 설계 호출 코드에 행위 변경이 없다.
- 다국어 계약 테스트와 Next.js 전체 빌드가 통과한다.
- 브라우저 요청은 기존 same-origin 경로를 유지한다.
