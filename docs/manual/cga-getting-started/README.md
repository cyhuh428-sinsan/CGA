# CGA Getting Started

상태: 브라우저 화면 확인 반영 초안
대상: CGA를 처음 사용하는 사용자

이 문서는 CGA에서 처음 봇을 만들고 첫 테스트 결과를 확인하는 과정을 안내합니다. 한 단계씩 따라 하며, 각 단계의 예상 결과를 확인한 후 다음 단계로 이동하십시오.

> 현재 봇 생성 화면의 메뉴명·필드·엔진 선택지는 인증된 CGA 화면에서 확인했습니다. 봇 생성 제출, 학습·인덱싱, 시뮬레이터 실행 결과는 아직 확인하지 않았으므로 해당 단계는 운영 확정 절차가 아닙니다.

## 이 문서에서 완성할 것

이 안내를 끝까지 읽으면 다음을 할 수 있습니다.

- 새 봇을 만들기 전에 필요한 정보를 준비할 수 있습니다.
- ML·Semantic·LLM 중 어떤 NLU 방식을 선택할지 판단할 수 있습니다.
- 생성 화면에서 모델·답변 방식·지원 상태를 확인할 수 있습니다.
- 봇 생성 이후 학습 또는 인덱싱과 첫 테스트에서 무엇을 확인해야 하는지 알 수 있습니다.

## 시작 전에 준비할 것

- CGA Studio 계정
- 생성할 봇 이름
- 테스트에 사용할 짧은 사용자 발화
- 사용할 NLU 방식에 대한 기본 선택

처음 화면을 익히는 경우에는 `ML`과 `정해진 답변` 조합을 기준으로 화면을 확인하는 것을 권장합니다. 이 조합은 현재 생성 화면에서 `실행/학습 가능`으로 표시됩니다. 실제 생성·학습 성공 여부는 별도 검증이 필요합니다.

엔진의 상세 선택 기준이 필요하면 [NLU 활용 가이드](../cga-nlu-guide/README.md)를 먼저 확인하십시오.

### 처음 사용할 때의 최소 준비 예시

처음부터 많은 기능을 넣지 말고, 하나의 의도와 짧은 테스트 발화로 화면 흐름을 확인합니다.

| 준비 항목 | 예시 |
|---|---|
| 봇 이름 | 휴가 문의 테스트봇 |
| 의도 | 휴가 잔여일 조회 |
| 학습문장 예시 | 남은 휴가가 며칠인가요? |
| 테스트 발화 | 휴가가 얼마나 남았나요? |
| 첫 답변 방식 | 정해진 답변 |

위 예시는 문서 사용법을 설명하기 위한 예시이며, 실제 회사 업무 데이터나 답변으로 그대로 사용하지 않습니다.

## 1단계. 로그인

### 목적

CGA Studio 작업 화면에 들어갑니다.

### 조작

1. CGA Studio 로그인 화면을 엽니다.
2. 계정 정보를 입력합니다.
3. 로그인 버튼을 선택합니다.

### 예상 결과

CGA Studio의 대시보드 또는 권한에 맞는 시작 화면이 표시됩니다.

### 문제가 생겼다면

로그인 화면으로 돌아가거나 권한 오류가 표시되면 계정 상태와 역할을 운영 담당자에게 확인합니다.

## 2단계. 새 봇 만들기

### 목적

테스트할 봇의 기본 정보를 입력합니다.

### 조작

1. 봇 생성 화면으로 이동합니다.
2. 봇 유형에서 `봇`을 선택합니다.
3. 텍스트형 또는 보이스형을 선택합니다.
4. 프로필 영역에서 PC 이미지를 선택할 수 있습니다.
5. `봇의 이름을 입력하세요.` 필드에 봇 이름을 입력합니다.
6. 언어에서 `한국어`를 확인합니다.
7. 필요하면 `봇을 설명할 수 있는 소개 문장을 입력하세요.` 필드에 소개를 입력합니다.

### 예상 결과

봇 생성 화면의 선택 상태와 구조 요약에 입력한 기본 정보가 표시됩니다.

### 문제가 생겼다면

봇 이름 오류가 표시되면 화면 안내에 맞지 않는 문자나 길이를 줄여 다시 입력합니다.

입력 전에 다음을 확인합니다.

- 봇 이름을 다른 봇과 혼동하지 않을 수 있는가
- 테스트 발화를 한 문장으로 준비했는가
- 실제 운영 데이터나 개인정보를 시험 입력에 사용하지 않았는가

## 3단계. NLU 방식 선택

### 목적

사용자 발화를 해석할 엔진을 선택합니다.

### 조작

`NLU 방식`에서 다음 중 하나를 선택합니다.

- `ML`
- `Semantic - Vector Worker`
- `Semantic - External Embedding`
- `LLM Engine`

### 예상 결과

선택한 방식에 맞는 NLU 모델과 추가 설정 항목이 표시됩니다. 예를 들어 `Semantic - External Embedding`을 선택하면 임베딩 모델과 Intent Vector DB 연결 항목이 표시되고, `LLM Engine`을 선택하면 Provider와 세부 모델 항목이 표시됩니다.

### 처음 선택하는 경우

- 학습문장과 의도를 직접 설계하는 시작점이라면 ML을 검토합니다.
- 의미 유사도와 Vector DB를 사용하는 구조라면 Semantic을 검토합니다.
- LLM Provider와 모델을 운영할 준비가 되어 있다면 LLM을 검토합니다.

구체적인 선택은 [엔진 비교표](../cga-nlu-guide/engine-comparison.md)를 참고합니다.

## 4단계. 모델과 답변 방식 확인

### 목적

선택한 NLU 방식에 필요한 모델과 답변 방식을 확인합니다.

### 조작

1. `NLU 모델`에서 선택 가능한 모델을 확인합니다.
2. `답변 방식`에서 정해진 답변, Semantic Engine RAG 답변, LLM Engine RAG 답변, LLM Engine 답변 중 선택 가능한 항목을 확인합니다.
3. 선택 조합의 지원 상태를 확인합니다.
4. 처음 설정을 확인할 때는 `ML` + `DeepLearning Lite` + `정해진 답변` 조합이 `실행/학습 가능`으로 표시되는지 확인합니다.

### 예상 결과

구조 요약에 언어, NLU 방식, NLU 모델, 답변 방식, LLM, 버전이 표시됩니다.

### 문제가 생겼다면

조합이 사용 불가로 표시되면 다른 답변 방식이나 NLU 방식을 선택합니다. 지원 상태를 확인하지 않고 생성을 진행하지 않습니다.

## 5단계. 엔진별 최소 준비

이 단계부터는 선택한 엔진에 따라 준비 내용이 달라집니다.

### ML

의도와 학습문장을 준비합니다. 한 발화에 하나의 의도만 포함하도록 작성하고, 비슷한 의도는 서로 구분되는 표현을 준비합니다.

처음에는 의도 하나와 학습문장 몇 개만 준비해 화면 흐름을 확인한 뒤, 성공 여부를 확인하고 범위를 넓힙니다.

### Semantic

의도 또는 검색 대상 지식과 Vector DB 연결 조건을 준비합니다. 외부 임베딩을 선택한 경우 검색 API 주소와 임베딩 모델 호환 조건을 확인합니다.

### LLM

LLM Provider와 세부 모델을 선택하고, 필요한 경우 모델 호출 주소와 답변 지시문을 준비합니다.

엔진별 상세 데이터 작성과 품질 개선은 [NLU 활용 가이드](../cga-nlu-guide/README.md)의 해당 장에서 다룹니다.

## 6단계. 생성·학습·인덱스 준비

### 목적

입력한 봇 설정과 데이터를 CGA에서 사용할 수 있는 상태로 준비합니다.

### 조작

1. 입력값과 엔진 조합을 다시 확인합니다.
2. 생성 화면의 `확인` 버튼을 선택합니다.
3. 생성 결과와 버전 상태를 확인합니다.
4. 선택한 엔진에 필요한 학습 또는 인덱스 준비 작업을 실행합니다.
5. 상태가 완료 또는 사용 가능한 상태로 바뀌었는지 확인합니다.

### 예상 결과

봇과 버전이 생성되고, 선택한 엔진에 맞는 준비 상태가 표시됩니다.

> `확인` 버튼과 생성 화면의 엔진별 설정 필드는 확인했지만, 제출 이후의 생성 결과·학습·인덱싱 완료 상태는 아직 검증하지 않았습니다. 실제 운영 절차로 확정하기 전에 브라우저 검증이 필요합니다.

## 7단계. 첫 테스트

### 목적

사용자 발화가 선택한 엔진을 통해 처리되는지 확인합니다.

### 조작

1. 생성한 봇의 버전 작업 화면으로 이동합니다.
2. 시뮬레이터를 엽니다.
3. 준비한 짧은 테스트 발화를 입력합니다.
4. 테스트를 실행합니다.

### 예상 결과

응답과 분류 결과가 표시됩니다.

### 문제가 생겼다면

응답이 없거나 예상과 다르면 봇·버전, 학습 또는 인덱스 상태, 선택한 엔진과 답변 방식을 먼저 확인합니다.

## 8단계. 결과 확인과 다음 학습

첫 테스트가 끝나면 다음 화면에서 결과를 확인합니다.

- 시뮬레이터: 입력 발화와 즉시 응답
- 분석: 누적 분류 결과와 적용 단계
- 평가: 평가 데이터와 결과
- 대화 이력: 저장된 대화 기록

결과가 부족하면 NLU 활용 가이드에서 엔진별 데이터 개선과 재검증 절차를 확인합니다.
