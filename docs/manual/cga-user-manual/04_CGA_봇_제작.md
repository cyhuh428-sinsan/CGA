# CGA Studio 사용자 매뉴얼

## 4장. 봇 제작

### 4.1 문서 목적

이 문서는 `봇 구성`에서 만든 후보를 실제 대화 작업 대상으로 옮겨 답변과 흐름을 다듬는 `봇 제작` 단계를 설명합니다.

### 4.2 사용 대상

- `03_CGA_봇_구성`을 완료한 사용자
- 의도 후보를 실제 대화 단위로 다듬으려는 사용자

### 4.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `04 봇 제작` 화면 진입
- 의도 목록 이해
- 대화 시작 화면 이해
- 대화 설계 화면 이해
- 저장 흐름 이해

## 5장. 봇 제작의 역할

`봇 제작`은 자동 생성된 후보를 실제 응답 가능한 대화로 다듬는 단계입니다.

이 단계의 목적:

1. 어떤 의도를 만들 것인지 확정한다.
2. 의도별 시작 구조를 확인한다.
3. 답변이나 대화 흐름을 수정한다.
4. 저장한다.

## 6장. 봇 제작 화면 열기

1. 좌측 워크플로우 메뉴에서 **04 봇 제작**을 클릭하세요.
2. 의도 목록 또는 대화 작업 본문이 보이는지 확인하세요.

노트:

- 운영 버전은 제작 작업을 제한할 수 있습니다.
- 수정은 보통 비운영 draft 버전에서 진행하는 것이 안전합니다.

## 7장. 의도 목록 이해

### 7.1 의도 목록의 의미

의도 목록은 현재 봇 버전에 포함된 대화 주제 목록입니다.

### 7.2 확인 절차

1. 의도 목록 표 또는 리스트를 확인하세요.
2. 의도 이름, 상태, 수정일 같은 정보가 보이는지 확인하세요.
3. 작업할 의도를 하나 선택하세요.

### 7.3 처음 사용자 권장 원칙

처음에는 가장 단순한 의도 1개만 선택해 작업하는 것이 좋습니다.

예시:

- 배송 조회
- 주문 취소
- 비밀번호 변경

## 8장. 대화 시작 화면 이해

### 8.1 대화 시작의 목적

대화 시작 화면은 사용자가 해당 의도에 들어왔을 때 어떤 시작 응답이나 시작 모듈이 배치되는지 확인하는 곳입니다.

### 8.2 확인 절차

1. 선택한 의도의 `대화 시작` 화면으로 이동하세요.
2. 시작 메시지 또는 시작 구조가 보이는지 확인하세요.
3. 기본 응답 문장이 자연스러운지 확인하세요.

## 9장. 대화 설계 화면 이해

### 9.1 대화 설계의 목적

대화 설계는 실제 응답 내용과 흐름을 편집하는 단계입니다.

### 9.2 확인 절차

1. `대화 설계` 화면으로 이동하세요.
2. 카드 이름, 기본 메시지, 답변 영역 같은 편집 요소가 보이는지 확인하세요.
3. 현재 답변 초안을 읽어보세요.

### 9.3 처음 사용자 권장 작업

처음 사용자라면 아래 정도만 수정해도 충분합니다.

1. 카드 이름이 너무 모호하면 정리
2. 기본 메시지 문장을 사용자가 이해하기 쉽게 수정
3. 필요 시 한두 줄 답변 보강

## 10장. 저장하기

### 10.1 저장 절차

1. 편집 후 저장 버튼을 찾습니다.
2. 저장을 클릭합니다.
3. 저장 완료 문구 또는 상태 반영을 확인합니다.

### 10.2 저장 후 확인

1. 다시 같은 의도를 열었을 때 수정한 값이 유지되는지 확인하세요.
2. 목록으로 돌아가 최근 수정 상태가 반영됐는지 확인하세요.

## 11장. 처음 사용자 권장 작업 순서

1. 의도 1개 선택
2. 대화 시작 확인
3. 대화 설계 진입
4. 기본 답변 수정
5. 저장
6. 다음 단계인 `봇 테스트`로 이동

## 12장. 자주 발생하는 문제와 해결 방법

### 12.1 어떤 의도부터 수정해야 할지 모르는 경우

가장 많이 들어올 질문이거나 가장 단순한 의도부터 시작하세요.

### 12.2 저장했는데 변화가 없는 경우

1. 현재 의도가 맞는지 확인하세요.
2. 운영 버전이 아니라 작업 가능한 버전인지 확인하세요.
3. 저장 완료 안내가 실제로 떴는지 확인하세요.

## 13장. 다음 작업

`봇 제작`이 끝나면 다음 단계는 **봇 테스트**입니다.

테스트 단계에서는 아래를 확인합니다.

1. 입력 문장을 넣었을 때 예상 의도가 선택되는지
2. 답변이 원하는 형태로 나오는지
3. 분석 데이터가 이상하지 않은지

## 14장. 이 문서에서 확인해야 할 최종 결과

1. `봇 제작` 화면으로 이동할 수 있다.
2. 의도 목록에서 작업 대상을 고를 수 있다.
3. 대화 시작과 대화 설계의 차이를 이해할 수 있다.
4. 기본 답변을 수정하고 저장할 수 있다.
