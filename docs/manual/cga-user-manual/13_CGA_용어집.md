# CGA Studio 사용자 매뉴얼

## 13장. 용어집

### 13.1 문서 목적

이 문서는 CGA Studio와 관련된 주요 용어를 빠르게 확인할 수 있도록 정리한 용어집입니다.

## 14장. 주요 용어

| 용어 | 설명 |
| --- | --- |
| 그룹 | 봇과 사용자가 소속되는 작업 단위입니다. |
| 봇 | 대화를 구성하고 운영하는 기본 단위입니다. |
| 버전 | 한 봇 이름 아래에서 관리되는 개별 작업본입니다. 실제 작업, 업로드, 다운로드는 버전 하나 기준으로 이해하는 것이 맞습니다. |
| draft | 운영 전 작업 중인 상태의 버전입니다. |
| 운영 버전 | 실제 서비스 연결 대상으로 지정된 버전입니다. |
| 작업 버전 | 현재 화면에서 열어 수정하거나 패키지 반출입 대상으로 삼는 버전입니다. 운영 버전과 다를 수 있습니다. |
| 봇 생성 | 새 봇과 초기 버전을 만드는 단계입니다. |
| 봇 설정 | 생성 이후 조정 가능한 기본 파라미터를 확인하는 단계입니다. |
| 봇 구성 | 학습문장 기반으로 의도 후보를 만드는 단계입니다. |
| 봇 제작 | 의도와 답변 흐름을 실제 대화로 다듬는 단계입니다. |
| 봇 테스트 | 시뮬레이터로 실제 문장을 넣어 결과를 확인하는 단계입니다. |
| 봇 평가 | 별도 평가 문장으로 모델 품질을 점검하는 단계입니다. |
| 재학습 | 운영 중 모은 문제 문장을 개선 대상으로 관리하는 단계입니다. |
| 분석 | 운영 중인 대화량과 문의 추이를 확인하는 단계입니다. |
| 의도 | 사용자의 질문 목적이나 대화 주제를 뜻합니다. |
| 학습문장 | 의도를 학습시키기 위한 질문 예시 문장입니다. |
| 공통 변수 | 여러 대화에서 공통으로 참조할 수 있는 변수입니다. |
| 시스템 변수 | 시스템이 런타임에 값을 채워주는 변수입니다. |
| 사용자 변수 | 운영자가 직접 등록해서 사용하는 변수입니다. |
| 기본 메시지 | 공통 상황에서 사용자에게 보여줄 기본 안내 메시지입니다. |
| Blocklist | 제외/무시/차단 대상으로 관리하는 단어 또는 패턴 목록입니다. |
| 룰 | 특정 패턴을 특정 의도나 모듈과 연결하는 규칙입니다. |
| 스몰토크 | 인사, 감사 등 일반 대화성 응답을 뜻합니다. |
| 채널 | WebChat 등 봇이 연결되는 접점입니다. |
| WebChat | 운영 버전 봇과 실제 대화를 진행하는 클라이언트 화면입니다. 작업 버전이 아니라 운영 버전에 연결됩니다. |
| Aidot 봇 패키지 업로드 | Aidot 호환 형식의 현재 작업 버전 1개를 반입하는 기능입니다. |
| CGA 버전 패키지 업로드 | CGA 보관/복원 형식의 현재 작업 버전 1개를 반입하는 기능입니다. |
