# CGA Studio 사용자 매뉴얼

## 2장. 봇 설정

### 2.1 문서 목적

이 문서는 이미 생성한 봇의 설정 값을 확인하고, 처음 사용자 관점에서 어떤 항목을 점검해야 하는지 설명합니다.  
이 문서를 따라하면 아래 작업을 수행할 수 있습니다.

- `봇 생성` 이후 `봇 설정` 화면으로 이동
- `봇 설정` 하위 메뉴 구조 이해
- AI 모델 설정 화면 확인
- 기본값 설정과 메시지 설정의 역할 이해
- 메신저 편의 기능, 제외/무시 목록, 룰 설정, 스몰토크 화면의 목적 이해
- 처음 사용자 기준으로 어디까지 수정하고 어디는 유지해야 하는지 판단

### 2.2 사용 대상

이 문서는 다음 사용자를 대상으로 합니다.

- `01_CGA_처음부터_봇_생성까지`를 완료한 사용자
- 방금 생성한 봇의 기본 설정을 확인하려는 사용자
- 이후 `봇 구성` 단계로 넘어가기 전에 주요 설정 항목을 점검하려는 사용자

### 2.3 문서 범위

이 문서에서는 아래 범위를 다룹니다.

- `봇 설정` 화면 진입
- 하위 메뉴 구조 확인
- 각 설정 화면의 역할 이해
- 초보 사용자 기준 권장 확인 절차

이 문서에서는 아직 다루지 않습니다.

- 의도/학습문장 직접 작성
- API 상세 연계 구현
- 실제 운영 버전 배포
- WebChat 실대화 검증

## 3장. 봇 설정 화면 개요

### 3.1 봇 설정의 역할

`봇 설정`은 새로 만든 봇의 동작 파라미터와 기본 운영값을 조정하는 단계입니다.

중요한 원칙:

- `봇 생성` 단계에서 정한 구조를 여기서 다시 뒤집는 것이 목적은 아닙니다.
- `봇 설정`은 생성 이후 조정 가능한 값들을 정리하는 단계입니다.
- 처음 사용자는 모든 값을 바꾸기보다, 화면의 의미를 이해하고 기본값을 확인하는 수준에서 시작하는 것이 좋습니다.

### 3.2 봇 설정 하위 메뉴

현재 CGA의 `봇 설정`에는 아래 하위 메뉴가 있습니다.

| 메뉴 | 역할 |
| --- | --- |
| AI 모델 설정 | AI 관련 기본 연결과 소개 영역을 확인합니다. |
| 기본값 설정 | 대화 기본 동작값을 확인합니다. |
| 메시지 설정 | 기본 응답 메시지 성격의 설정을 확인합니다. |
| 메신저 편의 기능 | 플로팅 버튼, 추천 의도 같은 메신저 편의 요소를 확인합니다. |
| 제외/무시 목록 설정 | Blocklist 성격의 제외/차단 대상을 확인합니다. |
| 룰 설정 | 특정 문장 패턴과 대상 의도/모듈 연결 규칙을 확인합니다. |
| 스몰토크 | 인사, 감사 등 일반 대화 응답 구성을 확인합니다. |
| 봇스테이션 | 외부 연계 상태를 확인합니다. |

노트:

- 처음 사용자에게 가장 중요한 화면은 `AI 모델 설정`, `기본값 설정`, `메시지 설정`입니다.
- 나머지 메뉴는 고급 운영 또는 품질 조정 단계에서 주로 사용합니다.

## 4장. 봇 설정 화면 열기

### 4.1 봇 작업공간에서 열기

`봇 설정` 화면을 열려면 다음 절차를 따르세요.

1. 좌측 메뉴에서 **봇 작업공간**을 클릭하세요.
2. 현재 작업할 봇을 선택하세요.
3. **봇 설정 열기** 버튼을 클릭하세요.

### 4.2 워크플로우 메뉴에서 열기

이미 봇 작업 중이라면 아래 절차로 이동할 수 있습니다.

1. 좌측 워크플로우에서 **02 봇 설정**을 클릭하세요.
2. 화면이 `봇 설정` 본문으로 바뀌는지 확인하세요.

정상 상태:

- 좌측에 `봇 설정` 하위 메뉴가 보입니다.
- 우측 본문이 선택한 하위 메뉴에 따라 바뀝니다.

## 5장. AI 모델 설정 확인하기

### 5.1 AI 모델 설정의 목적

`AI 모델 설정`은 봇의 AI 관련 기본 구성과 소개 영역을 확인하는 화면입니다.

이 화면에서는 일반적으로 아래 성격의 항목을 봅니다.

1. Intent Vector DB 연결
2. Answer Vector DB 연결
3. 구성 자동분류 가중치
4. 소개

### 5.2 처음 사용자 확인 절차

처음 사용자는 아래 순서로만 확인하면 됩니다.

1. 좌측 메뉴에서 **AI 모델 설정**을 클릭하세요.
2. `Intent Vector DB 연결` 영역이 보이는지 확인하세요.
3. `Answer Vector DB 연결` 영역이 보이는지 확인하세요.
4. `구성 자동분류 가중치` 영역이 보이는지 확인하세요.
5. `소개` 입력 영역이 보이는지 확인하세요.

### 5.3 처음 사용자 권장 원칙

처음 사용자는 아래처럼 접근하세요.

- Vector DB 연결 값은 기본 연결 기준으로 둡니다.
- 자동분류 가중치는 의미를 모르면 수정하지 않습니다.
- `소개`는 봇 용도를 설명하는 문장으로 보강할 수 있습니다.

예시:

- 고객센터 문의를 자동 분류하고 FAQ 답변을 제공하는 봇입니다.

주의:

- AI 연결 관련 값은 구조와 검색 품질에 영향을 줄 수 있으므로, 팀 기준이 없으면 임의 변경하지 마세요.

## 6장. 기본값 설정 확인하기

### 6.1 기본값 설정의 목적

`기본값 설정`은 사용자가 대화를 시작했을 때의 기본 동작값을 확인하는 화면입니다.

Brity 계열 기준으로 보면, 이 화면은 아래 성격의 값과 연결됩니다.

- 첫 인사말
- 의도 미이해 시 기본 응답
- 대화 종료 안내
- 버튼 입력 오류 시 안내

### 6.2 확인 절차

1. 좌측 메뉴에서 **기본값 설정**을 클릭하세요.
2. 기본 대화 관련 설정 블록이 보이는지 확인하세요.
3. 각 항목이 기본 메시지 또는 기본 동작값 형태로 정리되어 있는지 확인하세요.

### 6.3 처음 사용자 권장 원칙

처음에는 아래만 확인하면 충분합니다.

1. 첫 안내 메시지가 존재하는지
2. 오류 시 응답 기준이 비어 있지 않은지
3. 대화 종료 성격의 안내가 준비되어 있는지

노트:

- 이 단계에서 세부 문구를 완벽하게 다듬지 않아도 됩니다.
- 문구 정책은 이후 `기본 메시지 관리`와 함께 맞춰도 됩니다.

## 7장. 메시지 설정 확인하기

### 7.1 메시지 설정의 목적

`메시지 설정`은 봇이 공통 상황에서 사용자에게 보여줄 메시지 성격의 값을 확인하는 화면입니다.

예를 들면 아래 같은 메시지입니다.

1. 여러 의도가 후보로 나왔을 때 안내 메시지
2. 원하는 의도가 없을 때의 메시지
3. 시스템 오류 메시지
4. 타임아웃 메시지
5. 세션 종료 메시지

### 7.2 확인 절차

1. 좌측 메뉴에서 **메시지 설정**을 클릭하세요.
2. 메시지 관련 블록이 보이는지 확인하세요.
3. 주요 메시지가 비어 있지 않은지 확인하세요.

### 7.3 처음 사용자 권장 원칙

처음 사용자라면 아래 수준으로 확인하세요.

1. 핵심 메시지가 비어 있지 않은지
2. 한국어 봇이면 한국어 기준 메시지가 준비되어 있는지
3. 이상한 임시 문구가 남아 있지 않은지

## 8장. 메신저 편의 기능 확인하기

### 8.1 메신저 편의 기능의 목적

`메신저 편의 기능`은 메신저형 사용 경험을 보조하는 기능을 다룹니다.

대표적으로 아래 성격의 항목이 포함됩니다.

1. 플로팅 버튼
2. 추천 의도

### 8.2 확인 절차

1. 좌측 메뉴에서 **메신저 편의 기능**을 클릭하세요.
2. 플로팅 버튼 또는 추천 의도 관련 영역이 보이는지 확인하세요.
3. 추천 의도 목록이 구조적으로 보이는지 확인하세요.

### 8.3 처음 사용자 권장 원칙

- 이 기능은 필수 생성 단계는 아닙니다.
- 처음에는 존재 여부만 확인하고, 실제 운영 목적이 정해진 뒤에 다듬어도 됩니다.

## 9장. 제외/무시 목록 설정 확인하기

### 9.1 제외/무시 목록 설정의 목적

이 메뉴는 Blocklist 성격의 설정입니다.  
특정 단어, 패턴, 링크, 문장 등을 제외하거나 차단하는 규칙을 관리하는 데 사용합니다.

### 9.2 확인 절차

1. 좌측 메뉴에서 **제외/무시 목록 설정**을 클릭하세요.
2. 목록 테이블이 보이는지 확인하세요.
3. 항목의 이름, 유형, 사용 여부를 확인하세요.

### 9.3 처음 사용자 권장 원칙

- 처음 사용자라면 목록 구조만 확인하고 바로 수정하지 않아도 됩니다.
- 차단 정책은 운영 정책과 연결되므로 팀 기준이 있을 때만 수정하는 것이 좋습니다.

## 10장. 룰 설정 확인하기

### 10.1 룰 설정의 목적

`룰 설정`은 특정 표현식과 대상 의도/모듈을 연결하는 규칙 기반 설정입니다.

이 메뉴는 일반적인 NLU 기반 분류를 보완하는 역할을 합니다.

### 10.2 확인 절차

1. 좌측 메뉴에서 **룰 설정**을 클릭하세요.
2. 룰 목록 또는 룰 입력 영역이 보이는지 확인하세요.
3. 테스트 문장 영역이 있으면 구조를 확인하세요.

### 10.3 처음 사용자 권장 원칙

- 룰은 강한 동작 제어 수단이므로 의미를 충분히 이해한 뒤 수정해야 합니다.
- 처음에는 룰이 어떤 구조로 관리되는지만 확인하세요.

## 11장. 스몰토크 확인하기

### 11.1 스몰토크의 목적

`스몰토크`는 인사, 감사, 간단한 일상 표현처럼 업무 의도 외 일반 대화를 다루는 설정입니다.

### 11.2 확인 절차

1. 좌측 메뉴에서 **스몰토크**를 클릭하세요.
2. 스몰토크 이름, 우선순위, 메시지 수가 보이는지 확인하세요.
3. 사용자 메시지와 봇 메시지 입력 구조를 확인하세요.

### 11.3 처음 사용자 권장 원칙

- 업무 봇을 우선 만드는 경우 스몰토크는 나중에 다듬어도 됩니다.
- 다만 인사말 수준의 기본 응답이 준비되어 있는지는 확인하는 것이 좋습니다.

## 12장. 봇스테이션 확인하기

### 12.1 봇스테이션의 목적

`봇스테이션`은 외부 연계 상태나 운영 연결 상태를 확인하는 화면입니다.

### 12.2 확인 절차

1. 좌측 메뉴에서 **봇스테이션**을 클릭하세요.
2. 연결 상태, 연결 일시, 사용 여부 같은 정보가 보이는지 확인하세요.

### 12.3 처음 사용자 권장 원칙

- 처음 봇을 만드는 단계에서는 연계 상태를 읽는 수준이면 충분합니다.
- 실제 운영 연결 변경은 별도 운영 절차에 따라 진행하세요.

## 13장. 처음 사용자 권장 점검 순서

처음 사용자에게는 아래 순서를 권장합니다.

1. **AI 모델 설정**
2. **기본값 설정**
3. **메시지 설정**
4. **메신저 편의 기능**
5. 나머지 메뉴는 읽기 수준으로 확인

이 순서의 목적:

- 먼저 운영에 직접 영향을 주는 기본값을 이해하고
- 고급 기능은 구조만 파악한 뒤
- 본격적인 내용 작성은 `봇 구성` 단계에서 진행하기 위함입니다.

## 14장. 무엇을 수정해도 되고 무엇을 보류해야 하는가

### 14.1 처음 사용자에게 권장되는 수정 항목

처음 사용자에게는 아래 항목 정도만 권장합니다.

1. 소개 문장
2. 첫 안내 메시지 성격 확인
3. 오류/종료 기본 메시지 존재 여부 확인

### 14.2 바로 수정하지 않는 것이 좋은 항목

의미를 충분히 모를 경우 아래 항목은 바로 수정하지 않는 것이 좋습니다.

1. Vector DB 연결 관련 값
2. 자동분류 가중치
3. Blocklist 정책
4. 룰 표현식
5. 외부 연계 상태

## 15장. 자주 발생하는 문제와 해결 방법

### 15.1 어떤 메뉴부터 봐야 할지 모르는 경우

아래 3개만 먼저 확인하세요.

1. AI 모델 설정
2. 기본값 설정
3. 메시지 설정

### 15.2 값은 많은데 무엇을 바꿔야 할지 모르는 경우

처음에는 소개 문장과 기본 메시지 존재 여부만 확인하고 넘어가세요.

### 15.3 설정을 바꾸면 안 될 것 같은 불안이 드는 경우

그 판단이 맞습니다. 구조 영향이 있을 수 있는 값은 팀 기준 없이 임의 변경하지 않는 것이 안전합니다.

## 16장. 다음 작업

`봇 설정` 화면 확인이 끝나면 일반적으로 다음 단계는 **봇 구성**입니다.

다음 단계에서 주로 하게 되는 작업은 아래와 같습니다.

1. 의도 또는 답변 구조 확인
2. 질문 예시 입력
3. 문서 또는 답변 자산 연결
4. 대화 구조 점검

즉, `봇 설정`은 봇의 동작 바탕을 확인하는 단계이고, 실제 대화 내용을 만드는 작업은 다음 단계에서 본격적으로 진행합니다.

## 17장. 이 문서에서 확인해야 할 최종 결과

이 문서를 끝낸 사용자는 아래를 할 수 있어야 합니다.

1. `봇 설정` 화면으로 이동할 수 있다.
2. 하위 메뉴의 역할을 구분할 수 있다.
3. 처음 사용자 기준으로 우선 확인할 메뉴를 알고 있다.
4. 어떤 항목은 바로 수정해도 되고 어떤 항목은 보류해야 하는지 판단할 수 있다.
5. 다음 단계인 `봇 구성`으로 넘어갈 준비를 할 수 있다.
