# CGA Studio 사용자 매뉴얼

## 8장. 재학습

### 8.1 문서 목적

이 문서는 운영 과정에서 수집된 문제 문장이나 미처리 문장을 다시 학습 대상으로 관리하는 `재학습` 화면을 설명합니다.

### 8.2 사용 대상

- 기본 봇 제작과 테스트를 마친 사용자
- 운영 중 수집된 문장을 개선 대상으로 관리하려는 사용자

### 8.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `재학습` 화면 진입
- 조회 조건 이해
- 재학습 대상 리스트 이해
- 상태 구분 의미 이해

## 9장. 재학습의 역할

`재학습`은 사용자가 입력했지만 시스템이 충분히 잘 처리하지 못한 문장을 다시 개선 대상으로 다루는 단계입니다.

핵심 목적:

1. 문제 문장을 모은다.
2. 상태를 분류한다.
3. 다시 학습에 반영할지 판단한다.

## 10장. 재학습 화면 열기

1. 좌측 메뉴에서 **재학습**을 클릭하세요.
2. 필터 영역과 목록 영역이 보이는지 확인하세요.

## 11장. 조회 조건 이해

재학습 화면에서는 일반적으로 아래 같은 조건을 사용합니다.

1. 기간
2. 상태
3. 봇 또는 버전
4. 문장 검색

처음 사용자라면 아래만 먼저 보세요.

1. 어떤 상태 필터가 있는지
2. 기간 조회가 가능한지
3. 목록이 실제 문장을 보여주는지

## 12장. 상태 의미 이해

화면에 보일 수 있는 대표 상태 예시는 아래와 같습니다.

| 상태 | 의미 |
| --- | --- |
| 미학습 | 아직 반영하지 않은 대상 |
| 보류 | 바로 반영하지 않고 검토 중인 대상 |
| 재학습 제외 | 반영하지 않기로 한 대상 |
| 재학습 완료 | 이미 개선 작업에 반영된 대상 |

## 13장. 처음 사용자 권장 확인 절차

1. 목록에서 실제 문장 데이터가 보이는지 확인합니다.
2. 상태별로 어떤 대상이 있는지 봅니다.
3. 같은 문제가 반복되는지 눈으로 확인합니다.

노트:

- 처음 사용자에게 재학습은 “바로 수정 버튼을 누르는 작업”보다 “운영 중 어떤 문제 문장이 쌓이는지 이해하는 작업”에 가깝습니다.

## 14장. 재학습 결과를 어떻게 활용하는가

재학습 대상은 보통 아래 단계로 연결됩니다.

1. 의도 분류가 부족하면 `봇 구성`
2. 답변 내용이 부족하면 `봇 제작`
3. 운영 메시지 성격이 부족하면 `봇 설정`

## 15장. 이 문서에서 확인해야 할 최종 결과

1. `재학습` 화면으로 이동할 수 있다.
2. 재학습 대상 리스트의 의미를 이해할 수 있다.
3. 상태값의 차이를 이해할 수 있다.
4. 운영 중 생긴 문제를 어떤 단계에서 보완해야 할지 판단할 수 있다.
