# CGA Studio 사용자 매뉴얼

## 9장. 분석

### 9.1 문서 목적

이 문서는 운영 중인 봇의 대화량, 문의 내용, 기간별 사용 추이를 확인하는 `분석` 화면을 설명합니다.

### 9.2 사용 대상

- 운영 중인 봇의 사용 현황을 확인하려는 사용자
- 기간별 대화량과 문의 주제를 보고 개선 방향을 찾으려는 사용자

### 9.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `분석` 화면 진입
- 조회 조건 이해
- 대화량 및 문의 내용 확인
- 운영 개선 관점의 해석 방법

## 10장. 분석의 역할

`분석`은 현재 봇이 실제로 얼마나 사용되고 있는지, 어떤 문의가 많이 들어오는지 확인하는 단계입니다.

핵심 목적:

1. 사용량을 확인한다.
2. 자주 들어오는 질문을 본다.
3. 개선이 필요한 영역을 찾는다.

## 11장. 분석 화면 열기

1. 좌측 메뉴에서 **분석**을 클릭하세요.
2. 기간 필터와 차트 또는 표 영역이 보이는지 확인하세요.

## 12장. 조회 조건 이해

분석 화면에서는 일반적으로 아래 조건을 확인합니다.

1. 시작일
2. 종료일
3. 채널 또는 그룹
4. 기타 필터

처음 사용자 확인 포인트:

1. 기간을 바꾸면 결과가 바뀌는지
2. 어떤 기준으로 데이터를 자르는지
3. 합계와 세부 목록이 같이 보이는지

## 13장. 무엇을 먼저 봐야 하는가

처음 사용자라면 아래 순서로 보는 것이 좋습니다.

1. 전체 대화량
2. 기간별 추이
3. 자주 나온 문의 또는 주제
4. 응답이 부족했던 구간

## 14장. 분석 결과 활용 방법

분석 결과는 보통 아래 개선 작업으로 이어집니다.

1. 문의가 많은데 대응이 약하면 `봇 제작` 보강
2. 분류가 자주 어긋나면 `봇 구성` 보강
3. 운영 메시지가 부족하면 `봇 설정` 보강
4. 반복 실패 문장이 많으면 `재학습` 검토

## 15장. 이 문서에서 확인해야 할 최종 결과

1. `분석` 화면으로 이동할 수 있다.
2. 기간 기준 조회를 이해할 수 있다.
3. 대화량과 문의 추이를 읽을 수 있다.
4. 분석 결과를 어떤 개선 단계와 연결해야 하는지 판단할 수 있다.
