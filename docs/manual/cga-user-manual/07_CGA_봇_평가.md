# CGA Studio 사용자 매뉴얼

## 7장. 봇 평가

### 7.1 문서 목적

이 문서는 `봇 테스트` 이후 현재 봇의 이해력과 평가 이력을 확인하는 `봇 평가` 화면을 설명합니다.

### 7.2 사용 대상

- `05_CGA_봇_테스트`를 완료한 사용자
- 테스트 문장 기반 품질을 확인하려는 사용자

### 7.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `06 봇 평가` 화면 진입
- 평가 데이터 업로드 영역 이해
- 학습모델 평가 화면 이해
- 평가 이력 확인

## 8장. 봇 평가의 역할

`봇 평가`는 현재 만든 의도 모델이 얼마나 잘 분류되는지 점검하는 단계입니다.

핵심 목적:

1. 별도의 평가 문장으로 품질을 확인한다.
2. 평가 결과를 기록으로 남긴다.
3. 부족한 부분을 다시 `봇 구성` 또는 `봇 제작` 단계로 되돌린다.

## 9장. 봇 평가 화면 열기

1. 좌측 워크플로우 메뉴에서 **06 봇 평가**를 클릭하세요.
2. 평가 업로드 영역과 평가 이력 영역이 보이는지 확인하세요.

## 10장. 화면 구성 이해

| 영역 | 역할 |
| --- | --- |
| 평가 데이터 업로드 | 평가용 문장이나 파일을 넣는 시작 영역입니다. |
| 학습모델 평가 | 현재 모델 평가 결과를 보는 영역입니다. |
| 평가 이력 | 과거 평가 결과를 다시 확인하는 영역입니다. |

## 11장. 처음 사용자 확인 절차

처음 사용자라면 아래 순서로 확인하면 됩니다.

1. 평가 데이터를 올릴 수 있는 영역이 보이는지 확인합니다.
2. 현재 평가 화면에 어떤 지표가 노출되는지 확인합니다.
3. 하단 또는 본문에 평가 이력이 보이는지 확인합니다.

노트:

- 처음부터 평가를 완벽히 진행하기보다, 평가 화면 구조를 이해하고 나중에 정식 평가 데이터를 넣어보는 접근이 안전합니다.

## 12장. 평가 이력 보기

평가 이력에서는 아래를 확인합니다.

1. 언제 평가했는지
2. 어떤 버전 기준 평가인지
3. 결과가 어떻게 기록되는지

처음 사용자 확인 포인트:

1. 이력이 비어 있으면 아직 정식 평가를 하지 않은 상태일 수 있습니다.
2. 이력이 있다면 버전 기준이 현재 작업 대상과 맞는지 확인합니다.

## 13장. 평가 결과 해석의 기본 원칙

처음 사용자라면 아래 수준으로만 해석해도 충분합니다.

1. 잘 맞는 문장과 못 맞는 문장이 구분되는가
2. 특정 의도에서 계속 오류가 나는가
3. 다시 학습문장을 보강해야 하는가

## 14장. 문제가 있을 때 되돌아갈 단계

평가 결과가 좋지 않다면 아래 단계로 돌아갑니다.

1. 의도 구분이 잘못되면 `봇 구성`
2. 답변 흐름이 어색하면 `봇 제작`
3. 기본 메시지나 동작값이 이상하면 `봇 설정`

## 15장. 이 문서에서 확인해야 할 최종 결과

1. `봇 평가` 화면으로 이동할 수 있다.
2. 평가 데이터 업로드 영역의 의미를 이해할 수 있다.
3. 평가 이력을 확인할 수 있다.
4. 문제가 생기면 어느 단계로 돌아가야 할지 판단할 수 있다.
