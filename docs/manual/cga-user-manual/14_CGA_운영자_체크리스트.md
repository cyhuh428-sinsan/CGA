# CGA Studio 사용자 매뉴얼

## 14장. 운영자 체크리스트

### 14.1 문서 목적

이 문서는 새 봇을 만들고 기본 검토를 마친 운영자가 운영 전 확인해야 할 최소 체크리스트를 정리한 문서입니다.

## 15장. 운영 전 체크리스트

### 15.1 기본 생성 확인

1. 봇 이름이 최종 이름으로 저장되었는가
2. 버전 이름이 올바른가
3. 현재 작업 그룹이 맞는가

### 15.2 봇 설정 확인

1. 소개 문장이 비어 있지 않은가
2. 기본 메시지가 비어 있지 않은가
3. 의미를 모르는 고급 설정을 임의 변경하지 않았는가

### 15.3 봇 구성 확인

1. 학습문장이 최소한의 범위를 커버하는가
2. 의도 후보가 지나치게 넓거나 잘게 쪼개지지 않았는가
3. 현재 버전에 후보를 반영했는가

### 15.4 봇 제작 확인

1. 최소 1개 이상의 핵심 의도 답변을 점검했는가
2. 답변 문장이 사용자 관점에서 이해 가능한가
3. 저장 후 값이 유지되는가

### 15.5 봇 테스트 확인

1. 대표 질문으로 테스트했는가
2. 표현을 바꾼 질문으로도 테스트했는가
3. 엉뚱한 의도가 선택되지 않는가

### 15.6 버전 관리 확인

1. 현재 작업 버전과 운영 버전을 구분하고 있는가
2. 운영 버전을 직접 수정하지 않고 작업 버전에서 진행했는가
3. 필요 시 새 버전을 추가했는가

### 15.7 WebChat 확인

1. 운영 버전이 지정되어 있는가
2. WebChat 경로가 보이는가
3. 운영 버전 기준으로 채팅방 생성이 가능한가

### 15.8 운영 개선 확인

1. 평가 화면 구조를 확인했는가
2. 재학습 화면 구조를 확인했는가
3. 분석 화면에서 추이를 볼 수 있는가

## 16장. 체크리스트 사용 방법

이 체크리스트는 아래 시점에 사용하면 좋습니다.

1. 새 봇을 처음 만든 직후
2. 운영 버전을 바꾸기 전
3. WebChat 실제 연결 전
