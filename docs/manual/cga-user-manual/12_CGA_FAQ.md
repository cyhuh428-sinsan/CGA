# CGA Studio 사용자 매뉴얼

## 12장. 자주 묻는 질문

### 12.1 이 문서의 목적

이 문서는 CGA Studio를 처음 사용할 때 자주 나오는 질문과 짧은 답변을 정리한 FAQ입니다.

## 13장. FAQ

### Q1. `+ 봇 생성`을 눌렀는데 봇 이름이 자동으로 안 들어갑니다.

정상입니다.  
현재 CGA는 사용자가 직접 봇 이름을 입력해야 저장할 수 있습니다.

### Q2. 저장 버튼이 비활성화되어 있습니다.

아래를 먼저 확인하세요.

1. 봇 이름 입력 여부
2. 버전 이름 입력 여부
3. 현재 그룹의 생성 권한 여부

### Q3. `봇 생성`과 `봇 관리`는 무엇이 다릅니까?

- `봇 생성`은 새 봇을 만들고 기본 구조를 정하는 단계입니다.
- `봇 관리`는 이미 만든 봇의 버전, 다운로드/업로드, 운영 버전, WebChat 연결을 관리하는 화면입니다.

### Q4. 여러 버전이 있으면 어느 버전으로 대화합니까?

일반적으로 운영 버전으로 대화합니다.  
WebChat은 운영 버전 기준 연결 대상으로 이해하면 됩니다.

추가로 구분해야 할 점:

- 현재 화면에서 열어 둔 **작업 버전**과
- 실제 사용자 대화가 붙는 **운영 버전**은
- 서로 다를 수 있습니다.

또한 패키지 다운로드/업로드도 보통 현재 **작업 버전 1개** 기준으로 이해하는 것이 맞습니다.

### Q5. `봇 설정`에서 값을 함부로 바꿔도 됩니까?

처음 사용자라면 대부분의 고급 설정은 기본값 유지가 안전합니다.  
특히 Vector DB 연결, 가중치, 룰, Blocklist는 팀 기준 없이 임의 변경하지 않는 것이 좋습니다.

### Q6. `봇 구성`과 `봇 제작`은 무엇이 다릅니까?

- `봇 구성`은 학습문장으로 의도 후보를 만드는 단계입니다.
- `봇 제작`은 만들어진 후보를 실제 대화와 답변으로 다듬는 단계입니다.

### Q7. 테스트 결과가 이상하면 어디로 돌아가야 합니까?

문제 종류에 따라 다릅니다.

1. 의도 분류 문제: `봇 구성`
2. 답변 문장 문제: `봇 제작`
3. 기본 운영 메시지 문제: `봇 설정`

### Q8. `재학습`은 언제 사용합니까?

운영 중 실제 사용자 문장 중 잘 처리되지 않은 문장을 다시 개선 대상으로 모을 때 사용합니다.

### Q9. `분석`은 무엇을 보기 위한 화면입니까?

운영 중인 봇의 대화량, 기간별 추이, 많이 들어오는 문의를 보기 위한 화면입니다.

### Q10. 공통 변수의 시스템 변수는 왜 수정하면 안 됩니까?

시스템 변수를 시스템이 런타임에 채우는 값이기 때문입니다.  
예를 들어 `_bot_id` 같은 값은 봇이나 실행 상황에 따라 시스템이 넣어줍니다.

### Q11. `기본 메시지 관리`는 왜 언어별로 봐야 합니까?

사용자에게 보이는 메시지는 언어별로 달라야 하기 때문입니다.  
한국어 사용자는 한국어 메시지, 영어 사용자는 영어 메시지를 보게 됩니다.

### Q12. WebChat은 CGA 안의 화면입니까, 별도 프로그램입니까?

WebChat은 별도의 대화 클라이언트 성격의 화면입니다.  
CGA에서 관리하는 봇의 운영 버전에 연결해 실제 대화를 진행하는 용도로 사용합니다.
