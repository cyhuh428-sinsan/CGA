# CGA Studio 사용자 매뉴얼

## 5장. 봇 테스트

### 5.1 문서 목적

이 문서는 `봇 제작` 단계에서 만든 대화가 예상대로 동작하는지 확인하는 `봇 테스트` 단계를 설명합니다.

### 5.2 사용 대상

- `04_CGA_봇_제작`을 완료한 사용자
- 실제 질문을 넣어 대화 결과를 확인하려는 사용자

### 5.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `05 봇 테스트` 화면 진입
- 시뮬레이터 입력창 사용
- 대화 결과 확인
- 분석 패널 확인

## 6장. 봇 테스트의 역할

`봇 테스트`는 사용자가 실제 문장을 넣었을 때 봇이 어떤 의도를 선택하고 어떤 답변을 내는지 확인하는 단계입니다.

핵심 질문:

1. 내가 만든 의도가 선택되는가
2. 답변이 맞는가
3. 분석 결과가 이상하지 않은가

## 7장. 봇 테스트 화면 열기

1. 좌측 워크플로우 메뉴에서 **05 봇 테스트**를 클릭하세요.
2. 시뮬레이터 본문과 우측 분석 영역이 보이는지 확인하세요.

## 8장. 시뮬레이터 사용하기

### 8.1 입력 절차

1. 입력창을 클릭하세요.
2. 테스트할 문장을 입력하세요.
3. 전송 버튼을 누르세요.

예시:

- 배송 상태를 알려주세요
- 주문을 취소하고 싶어요
- 환불은 언제 되나요

### 8.2 결과 확인

전송 후 아래를 확인하세요.

1. 사용자 입력이 대화창에 표시되는지
2. 봇 응답이 이어서 표시되는지
3. 응답 문장이 예상과 크게 다르지 않은지

## 9장. 분석 패널 확인하기

우측 분석 패널에서는 보통 아래 성격의 정보를 확인합니다.

1. 선택된 의도
2. 추출된 정보
3. 런타임 변수 또는 분석 데이터

처음 사용자 확인 포인트:

1. 의도가 아예 엉뚱하지 않은지
2. 질문에 대한 응답 흐름이 끊기지 않는지
3. 비어 있는 값이 지나치게 많지 않은지

## 10장. 테스트 시나리오 예시

처음에는 아래처럼 간단하게 테스트하세요.

### 10.1 정상 질문 테스트

- 내가 만든 의도에 정확히 맞는 질문을 입력
- 예상 답변이 나오는지 확인

### 10.2 표현 변경 테스트

- 같은 의미를 다른 말로 입력
- 여전히 같은 의도가 선택되는지 확인

### 10.3 애매한 질문 테스트

- 조금 모호한 문장을 입력
- 시스템이 어떻게 반응하는지 확인

## 11장. 자주 발생하는 문제와 해결 방법

### 11.1 응답이 안 나오는 경우

1. 현재 작업 버전에 대화가 저장됐는지 확인하세요.
2. 테스트 중인 의도가 실제로 존재하는지 확인하세요.

### 11.2 엉뚱한 의도가 선택되는 경우

1. 학습문장 구성이 충분한지 확인하세요.
2. 후보를 너무 넓게 묶지 않았는지 확인하세요.
3. 답변 이전에 의도 정의를 다시 점검하세요.

### 11.3 답변 문장이 어색한 경우

`봇 제작` 단계로 돌아가 기본 메시지나 답변 초안을 수정하세요.

## 12장. 다음 작업

테스트 후에는 아래 중 하나로 진행합니다.

1. 결과가 좋으면 `봇 관리`에서 버전과 운영 준비를 확인
2. 결과가 부족하면 `봇 구성` 또는 `봇 제작`으로 돌아가 수정

## 13장. 이 문서에서 확인해야 할 최종 결과

1. `봇 테스트` 화면으로 이동할 수 있다.
2. 시뮬레이터 입력과 전송을 할 수 있다.
3. 대화 결과와 분석 패널을 함께 볼 수 있다.
4. 문제가 있으면 어느 단계로 되돌아가야 하는지 판단할 수 있다.
