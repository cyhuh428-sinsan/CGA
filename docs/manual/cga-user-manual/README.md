## 문서 성격

- 이 문서들은 Aidot 문체가 아니라 Brity 원본 사용자 매뉴얼의 장 구성과 설명 방식에 맞춰 정리했습니다.
- 화면 이름, 목적, 절차, 확인 결과를 분리해서 처음 사용자도 따라갈 수 있도록 구성했습니다.
- 현재 CGA Studio에 실제로 존재하는 화면과 흐름만 기준으로 작성했습니다.

## 현재 상태

- CGA 핵심 사용자 흐름 문서가 1차 완성되었습니다.
- 이후에는 실제 화면 캡처 삽입, 용어집 보강, 운영 시나리오 예제를 추가할 수 있습니다.
