# CGA Studio 사용자 매뉴얼

## 6장. 봇 관리와 버전

### 6.1 문서 목적

이 문서는 생성한 봇의 버전, 다운로드/업로드, 운영 설정, WebChat 연결 정보를 확인하는 `봇 관리` 화면을 설명합니다.

### 6.2 사용 대상

- 기본 봇 생성과 테스트까지 진행한 사용자
- 버전 추가, 운영 버전 확인, 패키지 입출력을 확인하려는 사용자

### 6.3 문서 범위

이 문서에서는 아래를 다룹니다.

- `봇 관리` 화면 진입
- 봇 목록 확인
- 버전 목록 확인
- 버전 추가
- 운영 설정 의미 이해
- 봇 다운로드/업로드, 버전 다운로드/업로드 구분 이해
- WebChat 열기 의미 이해

## 7장. 봇 관리의 역할

`봇 관리`는 제작 화면이 아니라, 봇 단위 자산과 버전, 패키지, 운영 상태를 관리하는 화면입니다.

핵심 역할:

1. 현재 봇의 버전 목록 확인
2. 새 버전 추가
3. 운영 버전 확인 또는 변경
4. 봇/버전 패키지 다운로드와 업로드
5. WebChat 연결 경로 확인

## 8장. 봇 관리 화면 열기

1. 좌측 메뉴에서 **봇 관리**를 클릭하세요.
2. 좌측에 봇 목록이 보이는지 확인하세요.
3. 중앙에 버전 목록이 보이는지 확인하세요.
4. 우측에 봇 상세 정보와 작업 버튼이 보이는지 확인하세요.

## 9장. 화면 구성 이해

| 영역 | 역할 |
| --- | --- |
| 좌측 봇 목록 | 그룹 내 봇을 선택합니다. |
| 중앙 버전 목록 | 선택한 봇의 버전을 확인합니다. |
| 우측 상세 정보 | 봇 ID, 이름, 운영버전, WebChat, 다운로드/업로드 버튼을 확인합니다. |

## 10장. 봇 선택하기

1. 좌측 봇 목록에서 원하는 봇을 클릭하세요.
2. 상단 선택 봇 정보가 바뀌는지 확인하세요.
3. 중앙 버전 목록이 해당 봇 기준으로 바뀌는지 확인하세요.

## 11장. 버전 목록 확인하기

버전 목록에서는 일반적으로 아래를 확인합니다.

1. 버전명
2. 상태
3. 비고
4. 운영 여부
5. 변경자
6. 최종수정

처음 사용자 확인 포인트:

1. 방금 만든 버전이 실제로 있는지
2. 현재 작업 버전이 무엇인지
3. 운영 버전이 따로 있는지

## 12장. 버전 추가하기

### 12.1 버전 추가의 의미

버전 추가는 현재 봇 안에 새로운 작업 버전을 만드는 기능입니다.

### 12.2 절차

1. 원하는 봇을 선택하세요.
2. **버전 추가** 버튼을 클릭하세요.
3. 새 버전이 목록에 추가되는지 확인하세요.

노트:

- 새 작업은 운영 버전을 직접 수정하기보다 새 버전에서 진행하는 것이 안전합니다.

## 13장. 운영 설정 이해하기

### 13.1 운영 설정의 의미

운영 설정은 여러 버전 중 실제 운영 대상으로 사용할 버전을 지정하는 기능입니다.

중요 원칙:

- 한 봇에는 여러 버전이 있을 수 있습니다.
- 그중 하나만 운영 버전이 됩니다.
- WebChat은 일반적으로 운영 버전에 연결됩니다.

### 13.2 확인 절차

1. 버전 목록에서 운영 여부를 확인하세요.
2. 특정 버전에 **운영 설정** 버튼이 있는지 확인하세요.
3. 현재 운영 버전이 무엇인지 우측 상세 정보에서도 확인하세요.

## 14장. 다운로드와 업로드 구분 이해하기

### 14.1 봇 다운로드 / 봇 업로드

- **봇 다운로드**: 봇 단위 패키지를 내려받습니다.
- **봇 업로드**: Aidot 호환 봇 패키지를 현재 CGA 봇 슬롯에 반영합니다.

### 14.2 버전 패키지 다운로드 / 버전 패키지 업로드

- **버전 패키지 다운로드**: 현재 선택 버전 기준 패키지를 내려받습니다.
- **버전 패키지 업로드**: 버전 단위 패키지를 올려 반영합니다.

### 14.3 처음 사용자 관점의 이해

쉽게 구분하면 아래와 같습니다.

| 기능 | 기준 단위 |
| --- | --- |
| 봇 다운로드 / 업로드 | 봇 단위 |
| 버전 패키지 다운로드 / 업로드 | 버전 단위 |

## 15장. WebChat 열기 이해하기

### 15.1 WebChat의 의미

`WebChat 열기`는 현재 봇의 채널 연결 기준 WebChat 접속 경로를 여는 기능입니다.

### 15.2 확인 절차

1. 우측 상세 정보에서 WebChat 주소가 보이는지 확인하세요.
2. **WebChat 열기** 버튼이 보이는지 확인하세요.
3. 현재 운영 버전과 연결된 의미인지 확인하세요.

노트:

- 운영 버전이 아닌 작업 버전은 WebChat 연결 대상이 아닐 수 있습니다.

## 16장. 처음 사용자 권장 작업 순서

1. 봇 선택
2. 버전 목록 확인
3. 새 버전 추가
4. 운영 버전 확인
5. WebChat 경로 확인
6. 필요 시 다운로드 기능만 읽기 수준으로 확인

## 17장. 자주 발생하는 문제와 해결 방법

### 17.1 업로드 후 변화가 없어 보이는 경우

1. 현재 선택한 봇이 맞는지 확인하세요.
2. 업로드 대상이 봇 단위인지 버전 단위인지 구분했는지 확인하세요.
3. 업로드 후 버전 목록과 우측 상세 정보가 갱신됐는지 확인하세요.

### 17.2 어떤 버전을 수정해야 할지 모르는 경우

운영 버전이 아닌 작업용 버전에서 먼저 수정하는 것을 권장합니다.

### 17.3 WebChat이 기대와 다르게 열리는 경우

운영 버전 기준 연결인지 먼저 확인하세요.

## 18장. 이 문서에서 확인해야 할 최종 결과

1. `봇 관리` 화면으로 이동할 수 있다.
2. 봇과 버전의 관계를 이해할 수 있다.
3. 운영 버전의 의미를 이해할 수 있다.
4. 봇 단위와 버전 단위 다운로드/업로드를 구분할 수 있다.
5. WebChat이 운영 버전과 연결된다는 점을 이해할 수 있다.
