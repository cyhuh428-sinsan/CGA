# CGA Studio 사용자 매뉴얼

## 15장. 예제 시나리오

### 15.1 문서 목적

이 문서는 처음 사용자나 운영자가 CGA Studio를 실제로 어떻게 따라갈 수 있는지 예제 시나리오 형태로 설명합니다.

## 16장. 예제 시나리오 1 - FAQ 봇 만들기

### 목표

고객센터 FAQ 봇 초안을 만들고 기본 테스트까지 진행합니다.

### 절차

1. 로그인합니다.
2. `봇 작업공간`에서 올바른 그룹을 선택합니다.
3. `+ 봇 생성`을 눌러 새 draft 봇을 만듭니다.
4. 아래처럼 입력합니다.

| 항목 | 예시 |
| --- | --- |
| 봇 이름 | 고객센터 FAQ 봇 |
| 설명 | 자주 묻는 질문에 답변하는 봇 |
| 기본 언어 | Korean |
| 버전 이름 | v1.0 |

5. 저장합니다.
6. `봇 설정`에서 소개 문장을 확인합니다.
7. `봇 구성`에서 아래 학습문장을 넣습니다.

- 배송 상태를 알려주세요
- 주문 취소하고 싶어요
- 환불은 언제 되나요
- 비밀번호를 변경하고 싶습니다

8. 의도 후보를 확인합니다.
9. 현재 버전에 반영합니다.
10. `봇 제작`에서 핵심 의도 하나의 답변을 다듬습니다.
11. `봇 테스트`에서 대표 질문을 넣어 결과를 확인합니다.

## 17장. 예제 시나리오 2 - 운영 전 점검

### 목표

이미 만든 봇을 운영 준비 관점에서 확인합니다.

### 절차

1. `봇 관리`로 이동합니다.
2. 봇과 버전 목록을 확인합니다.
3. 현재 운영 버전이 무엇인지 확인합니다.
4. 필요 시 새 작업 버전을 추가합니다.
5. WebChat 주소를 확인합니다.
6. `봇 평가`, `재학습`, `분석` 화면 구조를 확인합니다.

## 18장. 예제 시나리오 3 - WebChat 연결 확인

### 목표

운영 버전이 있는 봇으로 실제 채팅 연결을 시도합니다.

### 절차

1. `봇 관리`에서 운영 버전이 지정된 봇을 선택합니다.
2. `WebChat 열기`를 클릭합니다.
3. 서버 주소를 확인합니다.
4. 연결 테스트를 진행합니다.
5. 채팅방을 생성합니다.
6. 봇을 선택합니다.
7. 대표 질문을 입력해 응답을 확인합니다.
