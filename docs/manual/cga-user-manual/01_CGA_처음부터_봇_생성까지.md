# CGA Studio 사용자 매뉴얼

## 1장. 개요

### 1.1 문서 목적

이 문서는 CGA Studio를 처음 사용하는 사용자가 시스템에 접속하여 새 봇을 생성하고 저장하는 방법을 설명합니다.  
이 문서를 따라하면 아래 작업을 직접 수행할 수 있습니다.

- CGA Studio 접속
- 로그인
- 작업 그룹 확인
- 새 봇 draft 생성
- 봇 생성 화면 입력
- 저장 버튼 활성화
- 새 봇 저장
- 생성 결과 확인

### 1.2 사용 대상

이 문서는 다음 사용자를 대상으로 합니다.

- 처음으로 CGA Studio를 사용하는 사용자
- 그룹 내에서 새 봇을 생성해야 하는 운영자 또는 제작자
- 이후 `봇 설정`, `봇 구성`, `봇 제작`, `봇 테스트`로 이어질 작업을 시작하려는 사용자

### 1.3 문서 범위

이 문서에서는 아래 범위만 다룹니다.

- 로그인
- 작업 그룹 확인
- `봇 작업공간` 진입
- `+ 봇 생성`
- `01 봇 생성` 화면 입력
- 저장 및 생성 확인

이 문서에서는 아직 다루지 않습니다.

- 봇 설정 상세값 조정
- 의도/개체/사전 구성
- 버전 업로드/다운로드
- 운영 버전 지정
- WebChat 실제 대화 테스트

### 1.4 용어

| 용어 | 설명 |
| --- | --- |
| 그룹 | 봇을 소속시키는 작업 단위입니다. 사용 권한도 그룹 기준으로 적용됩니다. |
| 봇 | 대화를 구성하고 운영하는 기본 단위입니다. |
| 버전 | 한 봇 안에서 관리되는 개별 작업본입니다. |
| draft | 아직 운영 버전으로 지정되지 않은 작업 중 상태입니다. |
| 운영 버전 | 실제 운영 대상이 되는 버전입니다. |

### 1.5 표기 규칙

- 화면 이름, 메뉴 이름, 버튼 이름은 굵게 표시합니다.
- 사용자가 직접 입력해야 하는 값은 따옴표 없이 예시로 표시합니다.
- 주소, 식별자, 버전명은 코드 형식으로 표시합니다.

## 2장. 시작하기

### 2.1 접속 준비

CGA Studio를 사용하려면 아래 항목이 준비되어 있어야 합니다.

1. CGA Studio 접속 주소
2. 로그인 가능한 계정
3. 봇 생성 권한이 있는 그룹
4. 웹 브라우저

노트:

- 처음 사용하는 경우에는 팀에서 제공한 접속 주소와 계정을 먼저 확인하세요.
- 봇 생성 권한이 없는 계정으로 로그인하면 `+ 봇 생성`이 비활성화될 수 있습니다.

### 2.2 로그인하기

로그인하려면 다음 절차를 따르세요.

1. 웹 브라우저에서 CGA Studio 주소를 입력하여 접속하세요.
2. 로그인 화면이 나타나면 계정 정보를 입력하세요.
3. 로그인 버튼을 클릭하세요.

로그인 후에는 아래를 확인하세요.

1. 좌측 메뉴가 보이는지 확인합니다.
2. 상단에 현재 사용자, 그룹, 언어, 저장 버튼이 보이는지 확인합니다.
3. 기본 화면이 열리는지 확인합니다.

주의:

- 로그인은 되었지만 봇 목록이 전혀 보이지 않으면 권한 또는 그룹 배정 상태를 확인해야 합니다.

### 2.3 작업 그룹 확인하기

봇은 그룹 기준으로 생성되므로, 새 봇을 만들기 전에 현재 작업 그룹을 확인해야 합니다.

작업 그룹을 확인하려면 다음 절차를 따르세요.

1. 좌측 메뉴에서 **봇 작업공간**을 클릭하세요.
2. 화면 상단 또는 본문에서 현재 그룹 표시를 확인하세요.
3. 그룹 봇 목록이 보이는지 확인하세요.

확인 결과:

- 새 봇은 현재 선택된 그룹에 생성됩니다.
- 그룹이 다르면 저장 위치와 이후 권한이 달라집니다.

## 3장. 봇 생성 및 관리하기

### 3.1 봇 생성 화면 이해

새 봇을 만들기 전에 먼저 `봇 생성` 화면의 역할을 이해해야 합니다.

`봇 생성` 화면에서는 아래 항목을 정합니다.

| 항목 구분 | 설명 |
| --- | --- |
| 기본 정보 | 봇 이름, 설명, 기본 언어, 버전 이름을 입력합니다. |
| 구조 결정 | LLM 사용 여부, 입력 방식, 오케스트레이터 모드, Bot Server 위치 등 구조 관련 값을 확인합니다. |
| 기본 채널 | 운영 시 기준이 되는 기본 채널을 확인합니다. |
| 구조 요약 | 현재 선택한 구조를 우측 요약 영역에서 확인합니다. |

노트:

- 처음 사용하는 경우에는 구조 관련 항목을 임의로 바꾸기보다 기본값으로 시작하는 것이 안전합니다.

### 3.2 새 봇 draft 생성하기

새 봇 생성을 시작하려면 다음 절차를 따르세요.

1. **봇 작업공간** 화면으로 이동하세요.
2. **+ 봇 생성** 버튼을 클릭하세요.
3. 화면이 **01 봇 생성**으로 이동하는지 확인하세요.

정상적으로 이동하면 다음과 같은 상태가 됩니다.

- 새 draft 봇이 생성됩니다.
- 현재 작업 대상이 새 봇으로 바뀝니다.
- 상단 컨텍스트의 봇 정보가 새 작업 대상으로 갱신됩니다.

### 3.3 봇 생성 화면의 필수 입력 항목

새 봇을 저장하려면 최소한 아래 항목을 확인해야 합니다.

| 항목 | 설명 | 비고 |
| --- | --- | --- |
| 봇 이름 | 새 봇의 이름입니다. | 사용자가 직접 입력해야 합니다. |
| 설명 | 봇의 역할을 설명하는 문장입니다. | 권장 입력 |
| 기본 언어 | 봇의 기본 언어입니다. | 일반적으로 한국어 봇은 `Korean` 기준 |
| 버전 이름 | 최초 버전 이름입니다. | 저장 조건에 직접 영향 |

중요:

- 새 봇 생성 직후 봇 이름이 자동으로 완성되지 않는 것이 정상입니다.
- 사용자가 직접 입력해야 저장할 수 있습니다.

### 3.4 저장 버튼 활성화 규칙

현재 CGA Studio에서는 상단 **저장** 버튼이 항상 활성화되지 않습니다.

저장 버튼이 활성화되기 위한 기본 조건은 아래와 같습니다.

1. **봇 이름**이 입력되어 있어야 합니다.
2. **버전 이름**이 비어 있지 않아야 합니다.

아래 상태에서는 저장이 되지 않을 수 있습니다.

- 봇 이름이 비어 있음
- 버전 이름이 비어 있음
- 생성 권한이 없는 그룹 또는 계정

### 3.5 새 봇 정보 입력하기

새 봇을 입력하려면 다음 절차를 따르세요.

#### 3.5.1 봇 이름 입력

1. **봇 이름** 입력 칸을 클릭하세요.
2. 봇 이름을 입력하세요.

예시:

- 고객센터 FAQ 봇
- 주문 문의 응답 봇
- 사내 규정 안내 봇

입력 기준:

- 나중에 운영자가 보아도 용도를 구분할 수 있는 이름을 사용하세요.

#### 3.5.2 설명 입력

1. **설명** 입력 칸을 클릭하세요.
2. 봇의 목적을 한두 문장으로 입력하세요.

예시:

- 자주 묻는 질문에 자동으로 응답하는 고객 안내 봇입니다.

#### 3.5.3 기본 언어 확인

1. **기본 언어** 항목을 확인하세요.
2. 한국어 봇을 만드는 경우 한국어 기준으로 설정되어 있는지 확인하세요.

#### 3.5.4 버전 이름 입력

1. **버전 이름** 항목을 확인하세요.
2. 값이 비어 있으면 `v1.0`을 입력하세요.

권장 규칙:

- 첫 생성은 `v1.0`
- 이후 버전은 팀 규칙에 따라 `v1.1`, `v1.2` 또는 별도 버전명 사용

#### 3.5.5 구조 관련 항목 확인

처음 사용자라면 아래 구조 관련 항목은 기본값으로 두고 시작하는 것을 권장합니다.

1. 봇 구성에 LLM 사용
2. 구성 입력 방식
3. 오케스트레이터 모드
4. Bot Server 위치

주의:

- 이 항목들은 이후 구조와 동작에 영향을 줄 수 있으므로 의미를 모르는 상태에서 임의 변경하지 마세요.

#### 3.5.6 기본 채널 확인

1. **기본 채널** 영역을 확인하세요.
2. 현재 어떤 채널이 기준 채널로 보이는지 확인하세요.

노트:

- 처음 생성 단계에서는 일반적으로 `Web` 채널 기준으로 확인하면 됩니다.

### 3.6 저장하기

필수값 입력 후 저장하려면 다음 절차를 따르세요.

1. 상단 우측의 **저장** 버튼이 활성화되었는지 확인하세요.
2. **저장** 버튼을 클릭하세요.

정상 저장 후에는 아래 중 하나 이상이 보여야 합니다.

1. 저장 완료 메시지
2. 성공 안내 문구
3. 현재 작업 봇 정보 갱신

### 3.7 생성 결과 확인하기

저장 후 실제로 봇이 생성되었는지 확인하려면 다음 절차를 따르세요.

#### 3.7.1 상단 컨텍스트 확인

1. 상단의 현재 봇 이름이 방금 만든 이름으로 표시되는지 확인하세요.
2. 현재 버전이 입력한 버전명으로 보이는지 확인하세요.

#### 3.7.2 봇 작업공간에서 확인

1. 좌측 메뉴에서 **봇 작업공간**으로 이동하세요.
2. 그룹 봇 목록에서 방금 만든 봇이 보이는지 확인하세요.

#### 3.7.3 봇 관리에서 확인

1. 좌측 메뉴에서 **봇 관리**를 클릭하세요.
2. 좌측 봇 목록에서 방금 만든 봇을 선택하세요.
3. 중앙 버전 목록에서 생성한 버전이 보이는지 확인하세요.

## 5장. 자주 발생하는 문제와 해결 방법

### 5.1 저장 버튼이 비활성화된 경우

아래를 순서대로 확인하세요.

1. **봇 이름** 입력 여부
2. **버전 이름** 입력 여부
3. 현재 그룹의 생성 권한 여부
4. 로그인 상태와 작업 그룹 상태

### 5.2 저장 후에도 봇이 보이지 않는 경우

아래를 순서대로 확인하세요.

1. 현재 그룹이 올바른지 확인하세요.
2. **봇 작업공간**에서 다시 목록을 확인하세요.
3. **봇 관리**에서 다시 확인하세요.
4. 상단 현재 봇 정보가 바뀌었는지 확인하세요.

### 5.3 구조 항목을 어떻게 선택해야 할지 모르는 경우

처음 사용자는 아래 항목만 먼저 입력하고 저장해도 됩니다.

1. 봇 이름
2. 설명
3. 기본 언어
4. 버전 이름

나머지 구조 관련 값은 팀에서 정한 기본값을 유지하세요.

## 6장. 다음 작업

새 봇 생성을 완료한 후에는 일반적으로 아래 순서로 작업합니다.

1. **봇 설정**
2. **봇 구성**

4. **봇 테스트**
5. 필요 시 **봇 관리**에서 버전 확인

## 7장. 이 문서에서 확인해야 할 최종 결과

이 문서를 끝까지 수행한 사용자는 아래를 할 수 있어야 합니다.

1. CGA Studio에 로그인할 수 있다.
2. 작업 그룹을 확인할 수 있다.
3. **+ 봇 생성**으로 새 draft를 만들 수 있다.
4. `봇 생성` 화면의 필수 입력 항목을 구분할 수 있다.
5. 상단 **저장** 버튼을 활성화할 수 있다.
6. 새 봇을 저장할 수 있다.
7. 저장한 봇을 `봇 작업공간`과 `봇 관리`에서 다시 확인할 수 있다.
