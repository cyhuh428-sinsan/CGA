# CGA Studio 사용자 매뉴얼

## 11장. WebChat 사용

### 11.1 문서 목적

이 문서는 운영 버전에 연결된 WebChat을 열고, 채팅방을 만들고, 대화를 진행하는 기본 흐름을 설명합니다.

### 11.2 사용 대상

- 운영 버전이 지정된 봇을 가진 사용자
- WebChat 연결과 대화를 직접 확인하려는 사용자

### 11.3 문서 범위

이 문서에서는 아래를 다룹니다.

- WebChat 접속 주소 의미
- 서버 연결 테스트
- 채팅방 생성
- 봇 선택
- 대화 진행
- 대화 저장 의미

## 12장. WebChat의 역할

WebChat은 CGA가 아니라 별도의 대화 클라이언트 화면입니다.  
사용자는 이 화면에서 특정 서버와 특정 운영 버전 봇에 접속해 실제 대화를 진행합니다.

중요:

- WebChat은 아무 버전에나 붙는 것이 아니라 운영 버전 기준으로 연결됩니다.
- 봇이 여러 버전을 가지고 있어도 실제 채팅 연결 대상은 운영 버전입니다.
- 현재 작업 중인 버전이 따로 있어도, 운영 설정을 바꾸지 않았다면 WebChat 대상은 바뀌지 않습니다.

## 13장. WebChat 열기

### 13.1 봇 관리에서 열기

1. **봇 관리** 화면으로 이동하세요.
2. 원하는 봇을 선택하세요.
3. 우측 상세 정보에서 WebChat 주소 또는 **WebChat 열기** 버튼을 확인하세요.
4. 버튼을 클릭해 WebChat을 엽니다.

## 14장. 서버 연결 확인

WebChat 화면에서는 보통 아래 순서로 연결을 확인합니다.

1. 서버 주소 입력 또는 확인
2. **연결 테스트** 실행
3. 연결 성공 안내 확인

노트:

- 서버를 바꾸면 세션이나 채팅방 목록이 초기화될 수 있습니다.

## 15장. 채팅방 생성과 봇 선택

### 15.1 채팅방 생성

1. **채팅방 생성** 버튼을 클릭하세요.
2. 현재 서버에서 운영 버전이 있는 봇 목록이 보이는지 확인하세요.

### 15.2 봇 선택

1. 목록에서 원하는 봇을 선택하세요.
2. 선택 후 채팅방이 생성되는지 확인하세요.

중요:

- 모든 봇이 보이는 것이 아니라 운영 버전이 있는 봇이 보여야 합니다.
- 봇을 선택한다는 것은 그 운영 버전에 접속해 대화한다는 의미입니다.

## 16장. 대화 진행하기

1. 입력창에 메시지를 입력하세요.
2. 전송 버튼을 누르세요.
3. 사용자 메시지와 봇 응답이 순서대로 보이는지 확인하세요.

## 17장. 대화 저장

WebChat 화면에는 대화 저장 기능이 있을 수 있습니다.

이 기능은 현재 대화 기록을 저장하거나 기록 관리 대상으로 남기는 의미로 이해하면 됩니다.

## 18장. 문제가 있을 때 확인할 것

### 18.1 봇이 목록에 안 보이는 경우

1. 운영 버전이 지정되어 있는지 확인하세요.
2. 현재 서버가 올바른지 확인하세요.

### 18.2 연결 테스트가 실패하는 경우

1. 서버 주소가 맞는지 확인하세요.
2. 현재 서버가 실행 중인지 확인하세요.

### 18.3 대화는 열리는데 응답이 이상한 경우

1. 운영 버전이 기대한 버전인지 확인하세요.
2. `봇 테스트`, `봇 제작`, `봇 구성` 단계에서 다시 확인하세요.

## 19장. 이 문서에서 확인해야 할 최종 결과

1. WebChat이 별도 대화 클라이언트라는 점을 이해할 수 있다.
2. 서버 연결 테스트의 의미를 이해할 수 있다.
3. 운영 버전이 있는 봇을 선택해 채팅방을 만들 수 있다.
4. 실제 대화를 진행할 수 있다.
