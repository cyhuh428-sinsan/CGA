# CGA Studio 사용자 매뉴얼

## 10장. 관리자 기능

### 10.1 문서 목적

이 문서는 시스템 관리자가 사용하는 주요 관리자 화면을 설명합니다.

### 10.2 사용 대상

- 시스템 관리자
- 운영 관리자
- 조회 및 운영 통제 권한이 있는 사용자

### 10.3 문서 범위

이 문서에서는 아래를 다룹니다.

- 사용자 관리
- 로그인 이력
- 그룹 관리
- 대화 이력 조회
- 공통 변수 관리
- 기본 메시지 관리
- 채널 관리
- 봇스테이션 연계 현황
- 템플릿 목록

## 11장. 관리자 기능의 역할

관리자 기능은 봇 하나를 만드는 화면이 아니라, 전체 운영과 공통 자산을 관리하는 화면입니다.

핵심 역할:

1. 사용자와 권한 관리
2. 운영 이력 확인
3. 공통 자산 관리
4. 채널/연계 상태 확인

## 12장. 사용자 관리

사용자 관리에서는 아래를 확인합니다.

1. 사용자 목록
2. 권한 또는 역할
3. 사용 여부
4. 그룹 연결 정보

## 13장. 로그인 이력

로그인 이력에서는 아래를 확인합니다.

1. 누가 로그인했는지
2. 언제 로그인했는지
3. 어떤 결과로 처리됐는지

## 14장. 그룹 관리

그룹 관리는 봇과 사용자가 속한 운영 단위를 관리하는 화면입니다.

처음 확인할 내용:

1. 그룹 이름
2. 설명
3. 사용 여부

## 15장. 대화 이력 조회

대화 이력 조회는 운영 중 실제 대화를 확인하는 화면입니다.

확인 포인트:

1. 기간 기준 조회 가능 여부
2. 채널 기준 조회 가능 여부
3. 진행 중 대화도 조회 가능한지
4. 표에 상태와 최종 수정일시가 보이는지

## 16장. 공통 변수 관리

공통 변수에는 아래 두 종류가 있습니다.

1. 시스템 변수
2. 사용자 변수

중요:

- 시스템 변수는 시스템이 값을 채우는 값이므로 임의 수정/삭제 대상이 아닙니다.
- 사용자 변수는 운영 목적에 따라 추가/수정할 수 있습니다.

## 17장. 기본 메시지 관리

기본 메시지 관리는 언어별 공통 메시지를 관리하는 화면입니다.

확인 포인트:

1. 언어별 메시지 조회
2. 구분/사용여부 필터
3. 수정과 기본값 복원 흐름

## 18장. 채널 관리

채널 관리는 WebChat 등 채널 정의를 관리하는 화면입니다.

확인 포인트:

1. 채널 ID
2. 채널 이름
3. Provider
4. 인증 방식
5. 사용 여부

## 19장. 봇스테이션 연계 현황

이 화면은 봇과 외부 연계 상태를 운영 관점에서 보는 화면입니다.

확인 포인트:

1. 봇 이름
2. 그룹
3. 채널
4. 운영 버전
5. 상태

## 20장. 템플릿 목록

템플릿 목록은 기본 메시지, 카드, 버튼 등 재사용 템플릿 자산을 관리하는 화면입니다.

확인 포인트:

1. 채널
2. 템플릿 이름
3. 렌더러 타입
4. 아이템 타입
5. 사용 여부

## 21장. 처음 사용자 권장 원칙

처음 관리자 기능을 보는 사용자는 아래 순서로 접근하세요.

1. 조회 화면부터 이해
2. 공통 자산 구조 확인
3. 실제 수정은 운영 기준이 있을 때만 수행

## 22장. 이 문서에서 확인해야 할 최종 결과

1. 관리자 기능이 제작 화면과 다르다는 점을 이해할 수 있다.
2. 운영 이력, 공통 자산, 채널 관리의 역할을 구분할 수 있다.
3. 공통 변수와 기본 메시지의 중요성을 이해할 수 있다.
