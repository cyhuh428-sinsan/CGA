# CGA Studio 다국어 최종 감사 보고서

- 기준일: 2026-07-25
- 기준 브랜치: `fix/multilingual-final-audit`
- 기준 커밋: `main`의 `6af82ae`
- 대상 언어: 한국어, 영어, 중국어(간체), 일본어, 베트남어, 프랑스어, 독일어

## 1. 목적

기존 7개 언어 UI 적용 이후 남아 있던 동적 문구와 봇 테스트 화면의 언어 경계를 점검했다. 브라우저 UI만 수정했으며 API, NLU/ML/Semantic/LLM 실행 로직, 데이터 계약, Aidot 저장소는 변경하지 않았다.

## 2. 적용 원칙

- 화면 레이블과 분석 데이터 표시는 사용자가 선택한 UI 언어를 따른다.
- 봇의 기본 응답과 의도 미분류 응답은 봇에 설정된 언어를 따른다.
- 분석 로그의 내부 `cardType`, `cardName`, `description` 값은 기존 표준값을 유지한다.
- 분석 로그는 렌더링 시점에만 선택한 UI 언어로 변환한다.
- CSV 업로드 헤더와 저장 데이터의 상태값·식별자는 호환성을 위해 번역하지 않는다.
- Rich Form의 달력 요일, 시간 선택, 토글, 이미지, 동영상, 버튼, 입력 검증 기본값은 UI 언어를 따른다.

## 3. 수정 범위

- 분석, 대화 설정, 룰 설정, 버전 관리, 봇 허브, 의도 구성 화면의 동적 기본 문구
- 봇 테스트의 봇 언어/UI 언어 분리
- 봇 테스트 Rich Form 기본 레이블
- 봇 테스트 분석 로그, 변수 스냅샷, 동적 개체 추출 진단의 표시 언어
- 7개 언어 네이티브 런타임 문구 카탈로그
- 정적 회귀 계약 테스트

## 4. 기존 기능 보존 확인

- 브라우저 API 호출 및 same-origin/BFF 경계 변경 없음
- API 엔드포인트와 요청/응답 스키마 변경 없음
- NLU 학습, 분류, 룰, Semantic, LLM 실행 순서 변경 없음
- 분석 로그 내부 표준값 및 오류 판정 조건 유지
- CSV 헤더와 파일 호환 형식 유지
- Aidot 소스 변경 없음

## 6. 운영 반영 확인 항목

1. 영어 등 비한국어 UI에서 Admin 하위 메뉴와 본문이 같은 언어로 표시되는지 확인
2. UI 언어와 봇 언어를 다르게 설정한 뒤 봇 테스트 응답과 분석 데이터가 각각의 언어 기준을 따르는지 확인
3. Rich Form의 달력, 시간 선택, 토글, 미디어 대체 문구가 UI 언어를 따르는지 확인
4. 브라우저 Network에서 API 요청이 `/api/v1` 등 same-origin 경로인지 확인
5. Studio 컨테이너만 교체되고 API·Vector Worker 컨테이너가 유지되는지 확인
