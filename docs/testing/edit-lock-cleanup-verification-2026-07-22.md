# 만료 편집 잠금 자동 정리 검증 보고서

## 변경 목적

- 해제되지 않은 채 TTL이 지난 편집 잠금을 API가 자동으로 정리한다.
- 유효한 활성 잠금과 명시적으로 해제된 잠금 이력은 보존한다.

## 변경 범위

- API 시작 직후 및 60초 주기의 백그라운드 정리 작업
- 정리 활성화 여부와 실행 주기 환경 설정
- 만료 조건 및 배치 커밋 단위 테스트

## 검증 결과

- RED: 정리 서비스가 없는 상태에서 `ModuleNotFoundError` 확인
- 핵심 및 접근 회귀: 16 passed
- 전체 API 회귀: 525 passed, 4 skipped
- `git diff --check`: 통과

## 운영 확인 기준

1. 배포 전 활성/만료 잠금 건수를 기록한다.
2. API 재기동 후 60초 이내 만료 미해제 잠금이 0건인지 확인한다.
3. 활성 잠금 건수와 명시적 해제 이력이 유지되는지 확인한다.
4. `edit_lock.cleanup.completed` 로그의 삭제 건수를 확인한다.

## 알려진 비차단 경고

- Python 3.12 SQLite datetime adapter 사용 중단 예정 경고가 테스트에서 발생한다.
- Starlette의 `multipart` import 전환 예정 경고가 발생한다.
- 이번 변경과 무관하며 테스트 실패는 아니다.
