# CGA Studio 간단 사용 설명서

## 1. 로그인
- 접속 주소: `http://127.0.0.1:4173/`
- `user-id`, `password`를 입력하고 로그인합니다.
- 로그인 후 기본 진입 화면은 `봇 작업공간`입니다.

## 2. 봇 작업 시작
- `봇 작업공간`에서 현재 작업할 그룹을 선택합니다.
- 그룹 내 봇 목록에서 작업할 봇을 클릭합니다.
- 기존 봇을 작업하려면 하단의 `작업 봇 열기`를 누릅니다.
- 새 봇을 시작하려면 목록 상단의 `+ 봇 생성`을 누릅니다.
- 우측 패널의 `봇 설정 열기`, `봇 구성 열기`, `봇 관리 열기`로 바로 이동할 수 있습니다.

## 3. 봇 생성
- `봇 이름`, `설명`, `기본 언어`, `버전 이름`을 입력합니다.
- `봇 구성에 LLM 사용`, `구성 입력 방식`, `오케스트레이터 모드`, `Bot Server 위치`를 결정합니다.
- 우측 `Structure Summary`에서 현재 선택 결과를 확인합니다.
- 상단 `Save` 버튼으로 현재 설정을 저장합니다.

## 4. 봇 설정
- 좌측 워크플로우에서 `02 봇 설정`을 선택합니다.
- `서버 메뉴` 하위 항목을 펼쳐 `AI 모델 설정`, `기본값 설정`, `메시지 설정` 등을 확인합니다.
- 각 화면은 Aidot 본문 기준으로 연결되어 있습니다.

## 5. 봇 구성
- `03 봇 구성`에서 Aidot 기준 자동 구성 화면을 사용합니다.
- 학습문장 또는 PDF 기준으로 의도 후보를 생성합니다.
- CGA 원칙상 봇 구성은 LLM 중심입니다.

## 6. 봇 제작
- `04 봇 제작`에서 의도 목록을 확인합니다.
- 의도명을 클릭하면 `대화 시작`, `대화 설계` 화면으로 이어집니다.

## 7. 봇 테스트 / 평가 / 운영
- `05 봇 테스트`: Aidot 시뮬레이터 기준으로 테스트합니다.
- `06 봇 평가`: Aidot 평가 화면 기준으로 확인합니다.
- `재학습`, `분석`: Aidot 화면 기준으로 운영 상태를 확인합니다.

## 8. 봇 관리
- `봇 관리`에서는 봇 단위 자산과 버전을 관리합니다.
- 가능한 작업:
  - 봇 다운로드
  - 봇 업로드
  - 버전 추가
  - 버전 복사
  - 버전 삭제
  - 운영 버전 설정
- Aidot와 CGA는 봇 단위 업로드/다운로드 호환을 유지해야 합니다.

## 9. 확인 포인트
- 화면이 이상하면 먼저 현재 URL이 `http://127.0.0.1:4173/`인지 확인합니다.
- `Save`는 현재 작업 상태 저장용입니다.
- `Deploy`는 운영/테스트 관련 화면에서만 보입니다.
