1. 시스템 개요
CGA Studio는 봇 제작 순서를 중심으로 Aidot 기능을 재배치한 워크플로우 중심 봇 제작 플랫폼입니다. 사용자는 단계를 따라가기만 하면 완성된 챗봇을 빌드하고 운영할 수 있습니다.

1.2  전체 제작 단계
2. 글로벌 레이아웃
모든 화면은 아래 4영역 구조를 공유합니다.
3. 01단계 — 봇 생성
가장 먼저 진입하는 화면입니다. 봇의 이름과 기본 파라미터를 설정합니다. 복잡한 용어 없이 최소 입력만으로 봇 초안을 생성합니다.
4. 02단계 — 봇 구성
봇의 의도(Intent)를 LLM을 통해 구성하는 단계입니다. 두 가지 입력 경로 중 하나 또는 모두를 사용합니다.
4.1  두 가지 구성 경로
4.2  경로 A — 학습문장 → 의도 분류
질문 형태의 학습문장을 입력하면 LLM이 지정한 개수만큼 의도 그룹을 자동 분류합니다. LLM이 연결되지 않은 경우 수동 LLM Handoff를 통해 동일한 결과를 얻을 수 있습니다.

A-4  수동 LLM Handoff 화면 — 결과 가져오기
4.3  경로 B — PDF → Q&A 의도 생성
5. 의도 검수·편집
LLM이 생성한 의도 초안을 운영자가 검토하고 최종화합니다. 경로 A·B 모두 이 화면으로 연결됩니다.
6. 03단계 — 상세 설정
의도·답변 구성 이후 고급 사용자가 접근하는 세부 편집 화면입니다. 초급 사용자는 이 단계를 건너뛰고 빌드로 진행할 수 있습니다.
